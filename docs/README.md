# Project Page

This folder contains the GitHub Pages project page for the CVPR 2026 paper.

## Enabling GitHub Pages

1. Go to **Settings** > **Pages** in the GitHub repository
2. Under **Source**, select **Deploy from a branch**
3. Set branch to `update`, folder to `/docs`
4. Click **Save**

The project page will be available at:
`https://muxiddin19.github.io/Multimodal-Fingertip-Contact-Detection-via-Depth-and-Motion-Fusion/`
